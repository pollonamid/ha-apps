# Home Assistant App: Audio.cpp Vulkan

_Local speech-to-text server based on [audio.cpp](https://github.com/0xShug0/audio.cpp), with GPU acceleration through the Vulkan backend and [Wyoming protocol bridges](https://github.com/m-abs/wyoming_audiocpp) for Home Assistant voice assistants._

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

## Installation

Add this repository to your Home Assistant instance, then install **Audio.cpp Vulkan** from the app store. The app needs a GPU that Home Assistant OS can see under `/dev/dri`.
See [DOCS.md](./DOCS.md) for configuration and usage.
