# Home Assistant App: Audio.cpp

_Local speech-to-text server based on [audio.cpp](https://github.com/0xShug0/audio.cpp), with an OpenAI-compatible API and [Wyoming protocol bridges](https://github.com/m-abs/wyoming_audiocpp) for Home Assistant voice assistants._

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

## Installation

Add this repository to your Home Assistant instance, then install **Audio.cpp** from the app store.
See [DOCS.md](./DOCS.md) for configuration and usage.
